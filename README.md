#  Tank Düellosu

2 kişilik, aynı klavyeden oynanan top-down tank savaşı oyunu. Duvarların arkasına saklanıp rakibini vurmaya çalış.

**Oyna:** [Canlı link](https://emirhankrcbn.github.io/tank-duel/) *(GitHub Pages aktif edince çalışır)*

## Kontroller
| | Hareket | Ateş |
|---|---|---|
| Oyuncu 1 (Mavi) | `W A S D` | `F` |
| Oyuncu 2 (Kırmızı) | Ok tuşları | `Enter` |

## Özellikler
- Duvarlarla dolu bir arena, taktiksel saklanma
- Can barları, çarpışma algılama
- Web Audio API ile üretilen ses efektleri (ateş, çarpma, kazanma)
- Harici bağımlılık yok — tek HTML dosyası

## Teknoloji
Vanilla JavaScript + HTML5 Canvas
